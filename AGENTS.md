# Agent context: Workday Recruiting PM kit

This workspace holds **Cursor skills**, **rules**, and **agent briefs** for Product Management work on Workday Recruiting.

- **Skills** (workflows): [`.cursor/skills/`](.cursor/skills/) — duplicate [`_template-skill`](.cursor/skills/_template-skill/SKILL.md) to add new skills; each skill is a folder with `SKILL.md`.
- **Rules** (short context or personas): [`.cursor/rules/`](.cursor/rules/) — `.mdc` files; enable in Cursor or set `alwaysApply` as needed.
- **Sub-agent style briefs** (long prompts): [`agent-briefs/`](agent-briefs/) — paste into a chat or merge into rules/skills.

Fill stubs with your real glossary, stakeholders, and templates as they stabilize.
