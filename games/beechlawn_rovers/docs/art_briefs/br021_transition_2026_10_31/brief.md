# BR-021 live start and moving-turn footwork, 31 October 2026

BR-021 is **item 21 of 27, in progress**. This pass reduces sliding when the
actual 11v11 Shane #8 accelerates, turns 90 degrees and reverses. It changes
the runtime pose blend and ordinary movement-facing target only. The shared
65-bone rig, five authored gait clips, body/heads/kits, animation event markers,
ball physics and authoritative controller displacement are unchanged.

## Reference and measured gap

The owner's [Shane #8 roster sheet](../../../references/source_uploads/chat_attachments/character_roster_sheets/1-69014.jpg)
defines the silhouette, and the archived 69022 broadcast image establishes
gameplay readability. Neither is a captured gait. The earlier
[BR-021 stride pass](../br021_stride_2026_10_24/brief.md) reduced steady-run
toe slip but did not measure acceleration or direction changes. The same real
11v11 character, controller, rig, and pitch now run a repeatable 185-tick
sequence: start from rest, turn 90 degrees, then reverse. A world-space toe
sample counts a low, vertically quiet foot while the body moves faster than
0.5 m/s. This is a toe-joint proxy for visible stance, not a boot-sole or
force-plate measurement.

| 60 Hz phase | Baseline mean / p90 low-foot motion | New mean / p90 | Reduction in mean |
| --- | ---: | ---: | ---: |
| Start | 0.786 / 2.572 m/s | 0.474 / 1.502 m/s | 40% |
| 90-degree turn | 1.557 / 3.067 m/s | 0.571 / 1.030 m/s | 63% |
| Reversal | 1.846 / 3.643 m/s | 0.784 / 1.947 m/s | 58% |

The [comparison audit](comparison.json) is regenerated by
[`compare_br021_transition.py`](../../../tools/compare_br021_transition.py).
The [baseline trace](baseline_foot_trace.json), [24/s blend-only trace](blend24_foot_trace.json),
[rejected 60/s trial](blend60_foot_trace.json), and [final trace](final_foot_trace.json)
contain the frame-level roots, heading, speed and both toe positions. The
start improvement comes from advancing the visual gait blend at 24/s instead
of 10/s; 60/s increased the worst start slip and was rejected. On a moving
corner, the body now faces a target 25% toward new input from actual velocity
while velocity and input differ sharply. This keeps the in-place stance foot
aligned with the body's real travel arc. Keeper tracking, explicit skill and
aerial facing, slide/recovery, and committed pass/shot setup retain their own
facing rules. The measured root trajectory differs from baseline by at most
0.00000006 m, and sampled speed is identical. That supports the intended
visual scope in this isolated fixture; match feel still needs review.
