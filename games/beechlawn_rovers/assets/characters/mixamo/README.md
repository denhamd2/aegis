# Mixamo Y-Bot prototype asset

`y_bot_source.fbx` was supplied by the project owner as a Mixamo download.
`y_bot.glb` is the cleaned runtime export generated by
`tools/blender/beechlawn/export_mixamo_ybot.py`; `y_bot_source.blend` is the
editable Blender import. The 65 Mixamo bone names are preserved, helper
camera/light/cube objects are removed, and the one-frame FBX pose action is
not exported as a gameplay animation.

Preview: [Blender Workbench render](../../../docs/images/y_bot_import_preview.png).

The source FBX contains two skinned mesh parts (about 27.8k source vertices in
total) and no external image textures. Y-Bot is a stylized segmented robot
mannequin. Use it for skeleton, scale, and animation-pipeline validation; it is
not a likeness or final visual for Shane Denham or any Beechlawn player. The
Godot match-scene blockout remains the fallback until useful movement
clips and the human player meshes are ready.

Adobe's [Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)
states that Mixamo characters and animations may be used in video games. Keep
the asset in this project's game context rather than redistributing it as a
standalone asset pack.

`y_bot_animation_library.glb` contains the original locomotion and defensive
clips plus the 60 fps, 0.9-second right-foot pass blocking clip
(`AN_Beechlawn_PassRight`). The pass contact time is authored in Blender and
written to `y_bot_pass_contact.json`; Godot installs it as an AnimationPlayer
method event. The separate `y_bot_football_kick.glb` is retained as an isolated
single-action import check, not used by the reusable visual scene. Editable
Blender source and the repeatable authoring script live in `tools/blender/`.
