# Worn football source and usage note

The worn football visual was adapted from **“old used ball” by mik1190**,
provided by the project owner in `old used ball.zip` (BlendSwap asset 75068).
The ZIP contains a CC0 license page, and that same page identifies this
branded ball as fan art and says it must not be used commercially. The project
owner confirmed Beechlawn Rovers is **non-commercial**.

The Blender source and included license page are preserved under
`tools/blender/beechlawn/source/`. The game-ready mesh was resized to 22 cm,
reduced from about 124,844 to 4,368 triangles, and its packed texture was
reduced from 4K to 2K. The original source was not overwritten.

Do not include this asset in a commercial release. Before any commercial use,
replace it with an original or appropriately licensed football and verify the
replacement's branding and license.
