# Drop reference footage here

WWE 2K gameplay clips (or WWF No Mercy emulator captures as fallback) go in
this directory. They are frame-stepped to populate `timings.md`, `camera.md`,
and `hud.md`, and labeled frames get cut into `../frames/` and `../hud/`.

This directory is gitignored — clips stay local, only the measurements
derived from them (and cited frame crops) are committed.
