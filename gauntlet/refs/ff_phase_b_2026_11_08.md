## Changes

### 1. Chokeslam wiring

`ff/chokeslam_1.tres` was built in batch 1 but lived only in `match.tscn`'s
shared power pool. `TitleScreen.configure_match()` replaces that tier for every
roster entry, so no configured match could reach it.

`Roster` now lists it in Roman's power tier, and `test_ff_library` asserts both
the roster entry and the configured `power_move_pool` contain it.

### 2. Samoan Drop contact reauthor

The audited grip was 5.8 cm, over the 5 cm bar. The generic `legs` family was
holding the **far** thigh — the cradle a body slam uses — while the fireman's
carry holds the **near** thigh, the leg over the attacker's shoulder. The
upper-back target also sat on the body centreline.

A dedicated `legs_carry` family now holds the near thigh and the near surface
of the upper back. `power_samoan_drop` uses it; the `GRIP` exception for the
move is removed. No other move's contact targets changed.

### 3. One Winged Angel grip

The accumulated `PairedFit` corrections had been fitted more than once; the
baked defender offsets pushed the defender away from the attacker's hands.
The OWA fit was cleared, the clip rebuilt from the raw trajectory, then fitted
once and rebuilt again. The measured hold is now inside the bar.

The measured FF tempo is still **0.9 s to impact / 1.9 s to the finish**; the
current clip remains **1.333 s / 2.2 s**. The retime is a dedicated
choreography/contact pass (audit F1), not part of this grip fix. It is not
merged.

### 4. Per-move visual QA

Every built or fixed move now needs its own seven-beat sheet and a recorded
verdict. The ledger is `ff_visual_qa_ledger.md`; sheets live in
`gauntlet/refs/ff_review/moves/`. The renderer uses the side/close bare view on
Android because the match-camera path is too slow here; the match-camera view
is a Mac/CI follow-up.
